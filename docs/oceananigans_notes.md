# Oceananigans.jlの基礎学習

## 1. 目的

数式とコードの対応が分かりやすい実装方法を学ぶため，
Oceananigans.jlの基本的な機能について確認する．

## 2. 学習内容

### 2.1 GridとField

- RectilinearGrid：計算格子を作成する．
- CenterField：セル中心に物理量を定義する．
- set!：Fieldに値を設定する．

今回は4×4×4の格子を作成し，温度分布を T = x² とした．

### 2.2 一階微分

通常の差分計算：

```julia
dTdx = (T[i+1,j,k] - T[i,j,k]) / Δx
```

Oceananigans.jl：

```julia
dTdx = ∂x(T)
```

内部のセル境界面における計算結果：

[0.5, 1.0, 1.5]

理論値と一致した．

### 2.3 二階微分

通常の差分計算：

```julia
d2Tdx2 = (T[i+1,j,k] - 2*T[i,j,k] + T[i-1,j,k]) / Δx^2
```

Oceananigans.jl：

```julia
d2Tdx2 = ∂x(∂x(T))
```

中央の2セルにおける計算結果：

[2.0, 2.0]

理論値と一致した．

### 2.4 積分

```julia
I = Integral(T, dims=1)
```

x方向の積分結果は0.328125となった．

解析解は1/3であり，有限個のセルを用いて
積分を近似しているため，誤差が生じた．

### 2.5 演算の定義と実行

```julia
dTdx = ∂x(T)
dTdx_field = Field(dTdx)
compute!(dTdx_field)
```

演算の定義，結果を格納するFieldの作成，
実際の計算を分けて記述できる．

## 3. 物理量の定義位置

| 物理量 | x方向の定義位置 |
| --- | --- |
| 温度 | Center |
| 一階微分 | Face |
| 二階微分 | Center |
| x方向の積分 | Nothing |

一階微分では隣り合うセル中心の温度から傾きを
求めるため，その中間であるセル境界面に値が定義される．

二階微分ではセル境界面の値を用いて再び微分するため，
定義位置がセル中心に戻る．

Oceananigans.jlでは，微分する方向に応じて
物理量の定義位置が自動的に決まる．

## 4. 学習を通して分かったこと

- 数式に近い形で微分や積分を記述できる．
- 格子番号や格子幅を演算ごとに指定する必要がない．
- 微分による物理量の定義位置の変化が自動的に扱われる．
- 内部では数値的な計算が行われている．
